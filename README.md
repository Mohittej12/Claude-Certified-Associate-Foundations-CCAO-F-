# Claude Certified Associate - Foundations Practice Simulator

An unofficial browser-based practice simulator for the Claude Certified Associate Foundations (CCAO-F) exam.

## Features

- Ten independent practice exams with 60 questions each
- Domain-focused practice sets across all seven domains
- Timed exams with progress and answer persistence in the browser
- Scaled-score results, pass/fail status, domain breakdowns, and explanations
- Works as a standalone static website with no build step

## Use locally

Open `index.html` in a browser, or serve the folder with any static web server.
